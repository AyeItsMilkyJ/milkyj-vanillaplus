MILKYCRAFT VANILLA+ - OPTIONAL RECOMMENDED CONTROLS

This tool never runs automatically. Packwiz updates the tool, but it does not
manage or replace options.txt.

To apply the profile:
1. Launch MilkyCraft once so options.txt exists.
2. Close Minecraft completely.
3. Double-click APPLY RECOMMENDED CONTROLS.bat.

Only bindings still set to the pack's known defaults are changed. Any binding
you already customised is skipped. An exact timestamped backup is created in
the minecraft\milkycraft-control-backups folder before the first change.

To undo the profile, close Minecraft and double-click
RESTORE PREVIOUS CONTROLS.bat. Restoring returns the complete options file from
the latest pre-profile backup, so use it before making lots of newer settings
changes.

Useful defaults after applying:
  J             Quest book
  Ctrl+J        Teams
  B             Backpack
  Ctrl+B        New waypoint
  N             Wireless storage terminal
  Z             Zoom
  M             World map
  Ctrl+M        Enlarge minimap
  Alt+M         World-map settings
  R / U         JEI recipe / uses
  Ctrl+U        Death history
  F6 / F7 / F8 Shader reload / menu / toggle
  I / Alt+I     Aether accessories / Curios
  Ctrl+I        Relics ability selector

Use the installed Controlling mod's search and conflict views for later personal
changes. Fetzi's Displays' three optional shortcuts are left unbound because
version 1.1.0 registers them too late and they are not reliable.
